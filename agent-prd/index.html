1
业务场景
你是做什么行业的？什么业务？你在这个业务里扮演什么角色？（老板/运营/销售/操盘手）
2
当前痛点
现在这件事怎么干的？每天/每周最烦的那 1-2 件事是什么？如果把这 1-2 件事自动化了，能省多少时间？
3
理想状态
你希望 Agent 帮你做什么？用日常语言说。有现成的流程/SOP 文档直接发过来。
4
数据来源
Agent 需要读哪些数据？数据是固定的还是每天变化的？有现成的数据源还是需要 Agent 自己抓取？
5
产出物
Agent 最终要给你什么？（推送消息 / 自动填表 / 生成报告 / 自动回复客户）给谁看？（你自己 / 团队成员 / 客户）
6
使用频率 & 人数
什么时候用？几个人用？

预算范围
你愿意为这件事投入多少？（月付 / 一次性）不需要精确数字，给个区间就行。
